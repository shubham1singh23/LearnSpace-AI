## Run locally

See [README](../README.md) for configuration and test-database details. PowerShell:

```powershell
npm.cmd ci
Copy-Item .env.example .env
# Edit local database credentials in .env before continuing.
npm.cmd run db:up
npm.cmd run db:generate
npm.cmd run db:migrate
npm.cmd run db:seed
npm.cmd run dev
```

Open http://127.0.0.1:5173. An existing PostgreSQL installation can replace Compose after configuring a dedicated database URL. Production-local path: `npm run build`, set NODE_ENV=production, then `npm start` and open port 3001.
