# Ten largest engineering risks

Ordered by potential harm and implementation priority. Owners below are module roles for future tasks, not assigned people. Likelihood is an initial qualitative estimate.

| # | Risk / likelihood | Prevention and owner | Verification / recovery |
|---|---|---|---|
| 1 | Lost notes from autosave races, navigation or conflicting tabs / high | Editor + persistence: sequential saves, immutable snapshots, CAS, mutation receipts, local recovery draft, flush barrier | Type while request in flight; lose commit response; navigate/fail DB; conflict two tabs. Retain local JSON and offer explicit recovery, never silent overwrite. |
| 2 | AI edits corrupt wrong range or overwrite newer work / high | Editor + edits: stable IDs, exact slice hash, strict local sequence/revision guard, preview, one transaction, final server CAS | Emoji/multi-block fixtures; edit or undo while pending; competing tab. Reject stale operations; rerun from current selection. |
| 3 | Plausible but incorrect teaching / high | AI: bounded objectives, uncertainty, no fabricated verified citations, rubric fixtures, user editing | Human review varied subjects; code/examples inspected where possible. Correct notes explicitly and regenerate only with confirmation; no claim of guaranteed correctness. |
| 4 | Provider credential leakage or malicious local-origin request / medium | Config/API: env/session secrets, response allowlists, redaction, no hosted tracing by default, Host/Origin checks | Inspect bundles/network/log/export; inject raw provider errors; cross-origin mutation tests. Rotate exposed keys and fix redaction; no plaintext persisted UI keys. |
| 5 | Duplicate/interrupted generation and delayed stale commits / high | AI operations: active-scope unique index, leases/owner tokens, idempotency, guarded finalization, no automatic restart replay | Parallel requests, process restart, expired lease plus delayed completion. Mark interrupted and retry explicitly; preserve existing lesson. Billing exactly once is not guaranteed. |
| 6 | Inconsistent hierarchy/dependencies after edits / medium | Course domain: course lock, treeRevision CAS, recursive cycle check, same-course FKs, sibling indexes | Concurrent moves/adds/generation; cross-course parent; cycles and NULL root ordering. Roll back whole mutation, reload tree. |
| 7 | Document-schema drift causes edit/export/history loss / high | Shared schema/export: versioning, all-node visitors, reject unknown nodes, migration fixtures | Every supported node/mark round-trip; restore old schema; unsupported node errors. Preserve original JSON and require migration, never strip content silently. |
| 8 | Missing assets or export path/file vulnerabilities / medium | Assets/export: immutable ID-addressed files, version references/export pins, decoded file limits, path sanitization | GC/export race, orphan reconciliation, malicious titles/ZIP paths, missing/corrupt files. Fail preflight and retain files until references clear. |
| 9 | Provider capability/API drift and weak local-model structured output / high | AI factory: pinned packages, versioned registry, unknown capabilities conservative, Zod + semantic validators, bounded fallback | Per-adapter fixtures, optional live smoke including invalid credentials/model/rate limit. Disable unsupported action; keep saved data usable. |
| 10 | Seven-day scope exceeds reliable delivery capacity / high | Milestone owner: gate each vertical slice, avoid extra dependencies/scale work, record verified/deferred scope | Daily acceptance gates and final checklist. Extend work or label core preview; never waive data preservation tests to call it complete. |

Review this register after each daily gate. New observed failures should replace assumptions with evidence and link the regression test. Deferred encrypted key storage, collaboration and remote hosting each require fresh threat modeling before implementation.
